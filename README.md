# 燃刻 RANKE

一款面向手机端的离线健身与饮食记录工具。无需账号、无需服务器，安装后可直接在 iPhone 与安卓手机的主屏幕运行。

## 已实现

- 今日总览：热量摄入、基础代谢、运动消耗、预计总消耗与剩余热量
- 饮食数据库：内置生大米、鸡胸、鸡腿、酵母蛋白粉、食用油、腰果和核桃等常见食物
- 自定义食物：填写每 100g 的蛋白质、碳水和脂肪，按实际克数自动换算并保存复用
- 训练数据库：无氧按胸、背、肩、腿四个部位记录，有氧优先提供坡度走和爬楼机
- 训练消耗：按 MET、体重、时长和训练强度自动估算
- 身体记录：体重与体脂，近 7 天体重趋势
- 周期管理：本周疲劳管理周、本月增肌期
- 趋势洞察：7 日热量、训练容量、有氧时长与 14 天记录热力
- 本地优先：数据保存在设备浏览器中，支持 JSON 导出与导入
- 离线安装：完整 PWA 缓存，无网络也能启动和记录
- 键盘适配：底部表单跟随手机可视区域调整，输入框不会被输入法遮挡
- 液态玻璃：半透明卡片、背景模糊、高光边缘与轻微流动光效

## 运行

项目没有构建步骤和第三方依赖。将整个目录作为静态网站发布即可。

本地预览可使用：

```powershell
python -m http.server 4173
```

然后打开 `http://127.0.0.1:4173/`。

## 安装到手机

1. 将整个目录发布到任意 HTTPS 静态托管服务，例如 GitHub Pages、Cloudflare Pages 或 Netlify。
2. iPhone 使用 Safari 打开，点“分享” → “添加到主屏幕”。
3. 安卓使用 Chrome 打开，点菜单 → “安装应用”或“添加到主屏幕”。
4. 安装完成后，所有记录均可离线使用，不再需要电脑或局域网。

首次打开包含可操作的示例数据。进入“我的” → “清空并重新开始”即可保留个人资料并清除示例记录。

## 数据来源

基础食材营养值参考《中国食物成分表》与 USDA FoodData Central 的常见数据；复合菜使用同类菜品常见估算值。训练 MET 参考《体力活动纲要》（Compendium of Physical Activities）。这些值用于日常趋势管理，不应作为医疗建议或精密代谢测量结果。
